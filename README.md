# Diplom_3: UI Автотесты для Stellar Burgers
### Описание проекта
Этот проект содержит автоматизированные тесты для пользовательского интерфейса веб-приложения Stellar Burgers. Тесты проверяют ключевые функции: регистрацию пользователей, вход в систему и навигацию по разделам конструктора бургеров. Проект использует паттерн Page Object для описания элементов интерфейса, поддерживает тестирование в браузерах Google Chrome и Яндекс Браузер, и генерирует детальные отчёты с помощью Allure.

### Технологии
* Java 11 — основной язык программирования.
* JUnit 4 — для написания и запуска тестов.
* Selenium WebDriver - для взаимодействия с веб-браузером.
* REST Assured — для тестирования REST API.
* Allure — для генерации красивых отчётов о тестах.
* Maven — для управления зависимостями и сборки проекта.
